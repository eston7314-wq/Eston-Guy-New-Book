# Examples

Real records of the roster working together. Agent definitions alone do not show what happens
when the pipeline runs on an actual book; these do.

| Example | What it shows |
|---|---|
| [workflow-chapter-pipeline.md](workflow-chapter-pipeline.md) | One chapter (the introduction of a real book) through all six stages: what each agent read, wrote, flagged, and handed on, with word counts and durations |
| [workflow-consolidate-existing-drafts.md](workflow-consolidate-existing-drafts.md) | Importing 200,000 words of raw AI-assisted drafts, filling the config from the author's own material, and locking the author's structure against agent proposals |

## Adding an example

Record the dispatches, the reports, the flags, and the author decisions. Strip anything private
to the author. Good examples show the gates catching something.
