# Stage 2 Playbook: Research

> **Agent**: Book Researcher (Mode A) | **Parallelisable**: yes, across chapters, if each defers its Book Bible rows

## Objective
An evidence pack the writer can lean on and the fact checker can check against.

## Pre-conditions
- [ ] Blueprint block for the chapter exists
- [ ] Source passages for the chapter identified (source map) if source exists

## Inputs
blueprint block, source passages, Book Bible citations table, knowledge notes (glossary, sources already found).

## Outputs
`book/02-research/chNN-evidence.md`; Book Bible citation rows; knowledge notes extended.

## Quality gate
- [ ] 3 to 5 studies or reports, 2 to 3 statistics, 1 to 2 quotations, 1 real case, synthesis, counter-evidence
- [ ] Every item has URL or DOI; nothing from memory
- [ ] "Could not verify" list present, even if empty

## Handoff
Chapter card: what the evidence supports strongly, where it is weaker than the outline assumes, and which real cases are available for the story pass.
