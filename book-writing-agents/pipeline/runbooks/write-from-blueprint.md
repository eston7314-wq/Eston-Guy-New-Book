# ✏️ Runbook: Write From a Blueprint

> **Mode**: Book | **Agents**: all nine | **Typical**: 10 to 12 chapters, 45 to 65 thousand words

## Scenario
No drafts exist. The author has expertise, a niche, and perhaps a concept. The book is written from a locked blueprint, one chapter at a time.

## Execution plan
```
Stage 0: Book Strategist ideas → author picks → decision logged
Stage 1: Book Strategist blueprint → config filled → author rules on the author-only fields
Per chapter, in order (00, 01..N, 99):
  research → draft → story → devedit → factcheck → copyedit
Stage 6, 7, build
```

## Rules specific to this runbook
- The writer's `[AUTHOR STORY NEEDED]` slots are the author's homework; schedule them early because the conclusion returns to the introduction's story.
- Research for several chapters may run in parallel after the blueprint; everything else is sequential.
- Comparable-title research from stage 0 is reused by the marketer.
