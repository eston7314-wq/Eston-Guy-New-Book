# 🔁 Runbook: Second Edition Refresh

> **Mode**: Stage | **Agents**: Researcher, Developmental Editor, Copy Editor, Marketer, Launch Strategist

## Scenario
A published book needs updated evidence, a corrected chapter or two, and a relaunch.

## Execution plan
```
1. Import the published manuscript as book/05-final/ files and rebuild the Book Bible from it
2. Researcher fact-checks every chapter against current sources; open-claims.md lists what has changed
3. Developmental Editor revises only chapters with material changes; memo per chapter
4. Copy Editor finals; consistency decisions carried from edition one
5. Marketer updates description and keywords; Launch Strategist plans the relaunch and KDP update
```

## Rules specific to this runbook
- Nothing is rewritten for taste; only for changed facts or a documented weakness.
- The edition-one change logs are the baseline; every edit is a new change-log line.
