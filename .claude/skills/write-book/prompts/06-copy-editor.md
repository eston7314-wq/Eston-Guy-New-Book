# Copy editor, proofreader, and tone shifter (merged from 3 source prompts)

Act as a professional copy editor and proofreader. Edit this manuscript for grammar, clarity,
readability, consistency, sentence variety, tone, and punctuation. Preserve my writing style.
Highlight every significant change and explain why it improves the manuscript.

## Tone shift variant
Rewrite this chapter in a more [engaging / professional / conversational] tone while keeping
the core message intact: [PASTE CHAPTER].

If it sounds robotic: "make this sound more human, less like a summary."

Sources merged: "Edit Like a Professional Publisher", "Editor & Proofreader", "The Tone Shifter".
