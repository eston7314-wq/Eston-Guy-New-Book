## Standing rule (author instruction, 2026-11-20)

- **Always** move a newly approved final version of a chapter, the preface or the afterword into **Final Approved** as soon as it is made.
- When a new version replaces one already in Final Approved, rename the old one `SUPERSEDED - ...` and move it to **Old Versions**, so Final Approved never holds two versions of the same section.
- When a draft is replaced, rename the old draft `SUPERSEDED - ...` and move it to **Old Versions**.
- Never delete anything. Move it instead.
