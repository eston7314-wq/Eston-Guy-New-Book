# Book Bible

The running memory of the manuscript. Every writing or editing agent reads this before touching
a chapter and appends to it after. If it is not in here, a later chapter will contradict it or
repeat it.

## Voice and style rules

- Primary tone: warm and pastoral (author decision 2026-11-07, book.config.md)
- Sentence rhythm: mostly short. One long sentence per paragraph at most.
- Banned phrases: "in today's fast-paced world", "delve", "it's important to note",
  "game-changer", "unlock", "navigate the landscape", "at the end of the day",
  "in this chapter we will", any sentence that begins "Imagine a world where".
- Banned structures: three-item lists in every paragraph; rhetorical question openers
  more than once per chapter; a summary that restates the headings; a conclusion that recaps
  chapter titles.
- Reader is addressed as "you". Author is "I" (or "we" if config says so).

### Consistency decisions (copy editor appends; later chapters follow)

- (strategist, 2026-11-07, pending author) Scripture is quoted in the KJV/AKJV wording the thesis uses until the author chooses a translation. "The writer to the Hebrews", not "Paul", for Hebrews. Use "African heritage" as the umbrella term; use "Black Church" only for the institution.
- (strategist, 2026-11-07) Suicide passages follow the Samaritans media guidelines: no methods, and a help line nearby.
